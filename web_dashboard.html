Cryptographic Taxonomy & NIST Parameters

NIST FIPS 203 ML-KEM Standard

Module-Lattice-Based Key-Encapsulation Mechanism based on the hardness of Module Learning With Errors (M-LWE).

  • ML-KEM-512: 800B Public Key, 768B Ciphertext (NIST Category 1, AES-128 equivalent)
  • ML-KEM-768: 1,184B Public Key, 1,088B Ciphertext (NIST Category 3, AES-192 equivalent)
  • ML-KEM-1024: 1,568B Public Key, 1,568B Ciphertext (NIST Category 5, AES-256 equivalent)
RFC 5869 Dual HKDF Pipeline

Combines classical ECDH secret and post-quantum ML-KEM secret using domain-separated HKDF-Extract-and-Expand. Guarantees Dual Security: master key remains secure if either classical or post-quantum primitive holds.

Known Prototype Limitations
  • Classical certificate authentication (ECDSA P-256) used in TLS 1.3 handshake.
  • WireGuard prototype operates at userspace UDP level; not in-kernel wireguard.ko.
  • ML-KEM-512 is omitted from TLS 1.3 by OpenSSL 4.0.0 per NSA CNSA 2.0 guidance.
